# primitive_db - примитивная база данных 

Учебный проект МИФИ: консольная программа на Python которая имитирует работу с базой данных. Пакет `primitive_db` устанавливается как самостоятельная программа и запускается командой `database`.

## Установка

Нужен [uv](https://docs.astral.sh/uv/). Python 3.12 uv при отсутствие качает сам,

```bash
git clone https://github.com/aleksandrchalapov-cell/project-2_Chalapov_M26-555.git
cd project-2_Chalapov_M26-555
uv build
uv tool install dist/*.whl
database
```


Установка сразу с GitHub, без клонирования:

```bash
uv tool install git+https://github.com/aleksandrchalapov-cell/project-2_Chalapov_M26-555
```

запуск в режиме разработки, без установки:

```bash
uv sync
uv run database
```

## Управление таблицами 

| Команда | Что делает |
| --- | --- |
| `create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...` | создать таблицу |
| `list_tables` | показать список всех таблиц |
| `drop_table <имя_таблицы>` | удалить таблицу |
| `help` | справочная информация |
| `exit` | выход из программы |

- поддерживаемые типы данных: `int`, `str`, `bool`.
- столбец `ID:int` добавляется автоматически первым столбцом. Если указать `ID:int` вручную, он не задвоится; `ID` с другим типом считается ошибкой.
- метаданные таблиц (имена и столбцы) хранятся в файле `db_meta.json` в папке, из которой запущена программа, за счет этого таблицы сохраняются между запусками.


### Пример использования 

```
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

>>>Введите команду: create_table users name:str
Ошибка: Таблица "users" уже существует.

>>>Введите команду: list_tables
- users

>>>Введите команду: drop_table users
Таблица "users" успешно удалена.

>>>Введите команду: drop_table products
Ошибка: Таблица "products" не существует.
```

### Ошибки ввода

- Неизвестная команда: `Функции <команда> нет. Попробуйте снова.`
- Неверный или пропущенный тип столбца, повтор имени столбца, неверное число аргументов команды, незакрытая кавычка: `Некорректное значение: <значение>. Попробуйте снова.`
- Пустая строка: запрос команды повторяется. Если таблицы нет, `list_tables` выводит "Таблиц пока нет."
- Ctrl+C или Ctrl+D: выход из программы.
