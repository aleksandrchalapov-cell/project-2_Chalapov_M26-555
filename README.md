# primitive_db - примитивная база данных 

Учебный проект МИФИ: консольная программа на Python которая имитирует работу с базой данных. Пакет `primitive_db` устанавливается как самостоятельная программа и запускается командой `database`.

## Установка

Нужен [uv](https://docs.astral.sh/uv/). Python 3.12 uv при отсутствие качает сам,

```bash
git clone https://github.com/aleksandrchalapov-cell/project-2_Chalapov_M26-555.git
cd project-2_Chalapov_M26-555
uv build
uv tool install dist/*.whl
database
```


Установка сразу с GitHub, без клонирования:

```bash
uv tool install git+https://github.com/aleksandrchalapov-cell/project-2_Chalapov_M26-555
```

запуск в режиме разработки, без установки:

```bash
uv sync
uv run database
```

## Управление таблицами 

| Команда | Что делает |
| --- | --- |
| `create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...` | создать таблицу |
| `list_tables` | показать список всех таблиц |
| `drop_table <имя_таблицы>` | удалить таблицу |
| `help` | справочная информация |
| `exit` | выход из программы |

- поддерживаемые типы данных: `int`, `str`, `bool`.
- столбец `ID:int` добавляется автоматически первым столбцом. Если указать `ID:int` вручную, он не задвоится; `ID` с другим типом считается ошибкой.
- метаданные таблиц (имена и столбцы) хранятся в файле `db_meta.json` в папке, из которой запущена программа, за счет этого таблицы сохраняются между запусками.
- имя таблицы может состоять из букв, цифр и `_` и не может начинаться с цифры: оно становится именем файла с записями.

### Пример использования 

```
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

>>>Введите команду: create_table users name:str
Ошибка: Таблица "users" уже существует.

>>>Введите команду: list_tables
- users

>>>Введите команду: drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: y
Таблица "users" успешно удалена.

>>>Введите команду: drop_table products
Ошибка: Таблица "products" не существует.
```

### Ошибки ввода

- Неизвестная команда: `Функции <команда> нет. Попробуйте снова.`
- Неверный или пропущенный тип столбца, повтор имени столбца, неверное число аргументов команды, незакрытая кавычка: `Некорректное значение: <значение>. Попробуйте снова.`
- Пустая строка: запрос команды повторяется. Если таблицы нет, `list_tables` выводит "Таблиц пока нет."
- Ctrl+C или Ctrl+D: выход из программы.

## CRUD-операции

| Команда | Что делает |
| --- | --- |
| `insert into <имя_таблицы> values (<значение1>, <значение2>, ...)` | создать запись |
| `select from <имя_таблицы>` | прочитать все записи |
| `select from <имя_таблицы> where <столбец> = <значение>` | прочитать записи по условию |
| `update <имя_таблицы> set <столбец1> = <новое_значение1> where <столбец_условия> = <значение_условия>` | обновить записи |
| `delete from <имя_таблицы> where <столбец> = <значение>` | удалить записи |
| `info <имя_таблицы>` | вывести информацию о таблице |

- строки записываются только в кавычках (`"Sergei"` или `'Sergei'`), целые числа без кавычек (`28`, `-5`), логические значения как `true` или `false`.
- `ID` в `insert` не указывается: программа назначает его сама (наибольший ID + 1). Остальные столбцы обязательны.
- типы значений проверяются по схеме таблицы, в том числе в `where` и `set`. `ID` изменить нельзя.
- `set` может менять несколько столбцов через запятую: `set age = 29, is_active = false`. В `where` указывается одно условие.
- записи каждой таблицы хранятся в файле `data/<имя_таблицы>.json` в той же папке, что и `db_meta.json`. `drop_table` удаляет и этот файл.

### Пример использования

```
>>>Введите команду: insert into users values ("Sergei", 28, true)
Запись с ID=1 успешно добавлена в таблицу "users".
Функция insert выполнилась за 0.000 секунд.

>>>Введите команду: select from users where age = 28
Функция select выполнилась за 0.000 секунд.
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  28 |    True   |
+----+--------+-----+-----------+

>>>Введите команду: update users set age = 29 where name = "Sergei"
Запись с ID=1 в таблице "users" успешно обновлена.

>>>Введите команду: delete from users where ID = 1
Вы уверены, что хотите выполнить "удаление записи"? [y/n]: y
Запись с ID=1 успешно удалена из таблицы "users".

>>>Введите команду: info users
Таблица: users
Столбцы: ID:int, name:str, age:int, is_active:bool
Количество записей: 0
```

### Ошибки ввода

- нет такой таблицы: `Ошибка: Таблица "<имя>" не существует.`
- нет такого столбца: `Ошибка: Столбец "<столбец>" не существует.`
- неверное число значений в `insert`: `Ошибка: Ожидается значений: <N>, получено: <M>.`
- значение не того типа: `Некорректное значение: <значение>. Попробуйте снова.` Строка показывается в кавычках, чтобы было видно, что это строка.
- попытка изменить `ID`: `Ошибка: Столбец "ID" нельзя изменить.`
- условию не подошла ни одна запись: `Записи не найдены.`
- команда записана неверно (строка без кавычек, нет скобок, `=` или `where`): `Некорректное значение: <вся команда>. Попробуйте снова.`

## Обработка ошибок и подтверждение действий

- ошибки обрабатываются в одном месте, декоратором `handle_db_errors` из `decorators.py`: программа выводит сообщение (см. «Ошибки ввода» выше) и ждёт следующую команду. На неожиданную ошибку выводится `Произошла непредвиденная ошибка: <описание>`.
- удаление таблицы (`drop_table`) и удаление записей (`delete`) нужно подтвердить: декоратор `confirm_action` спрашивает `Вы уверены, что хотите выполнить "<действие>"? [y/n]:`. Любой ответ, кроме `y`, а также Ctrl+C или Ctrl+D отменяют операцию. Вопрос задаётся, только если удалять есть что: таблица существует, условию подходят записи.
- `insert` и `select` сообщают время выполнения (декоратор `log_time`): `Функция select выполнилась за 0.000 секунд.`
- результаты `select` кэшируются (замыкание `create_cacher`): повторный одинаковый запрос берётся из памяти без чтения файла, поэтому строки о времени у него нет. После любого изменения данных кэш сбрасывается.

### Пример

```
>>>Введите команду: select from users where age = 28
Функция select выполнилась за 0.000 секунд.
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  28 |    True   |
+----+--------+-----+-----------+

>>>Введите команду: select from users where age = 28
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  28 |    True   |
+----+--------+-----+-----------+

>>>Введите команду: delete from users where ID = 1
Вы уверены, что хотите выполнить "удаление записи"? [y/n]: n
Операция отменена.

>>>Введите команду: drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: y
Таблица "users" успешно удалена.
```
